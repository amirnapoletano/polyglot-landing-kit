# Landing Page Starter Kit

A clean, modern landing page starter kit (HTML/CSS/JS) with:
- Hero + features + pricing + testimonials + CTA
- Dark mode (system + toggle)
- Subtle reveal animations (respects reduced motion)
- Responsive layout

## Use
Open `index.html` in your browser, or deploy as static site.

## Customize
Edit `style.css` tokens in `:root` and `body[data-theme="dark"]`.
